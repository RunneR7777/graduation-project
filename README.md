# IPv6网络检测分析系统使用说明文档

## 系统概述

IPv6网络检测分析系统是一个专为IPv6网络环境设计的网络监控与安全分析平台，主要用于IPv6网络流量分析、主机监控、活跃地址检测和风险暴露面分析。系统提供直观的可视化界面，帮助管理员全面了解网络状况，及时发现并处理潜在安全风险。

## 系统架构

系统分为以下几个主要功能模块：

1. **网络流量分析**：监控和分析网络流量，包括所有流量、进站流量、出站流量和危险流量
2. **主机分析**：对远端主机进行监控和分析，识别潜在的危险主机，提供AS分布和国家分布统计
3. **IPv6地址分析**：检测IPv6活跃地址，分析地址生成模式，提供地址统计数据
4. **风险管理**：分析系统的安全风险，包括端口风险和地理位置分布
5. **系统管理**：提供系统设置和API文档等功能

## 页面功能说明

### 1. 仪表盘

**路径**：`/dashboard`

**功能**：系统总览页面，提供网络状态的整体视图和关键指标。

**主要组件**：
- 流量流向卡片：显示活跃流数量、危险流数量和评分
- 主机卡片：显示本地主机数、远程主机数和危险主机数
- 活跃地址卡片：显示活跃IPv6地址数量和异常地址数量
- 端口风险卡片：显示开放端口数量和高风险端口数量
- 流量分类图表：按协议类型分类的流量分布
- 热门应用图表：最常用的网络应用
- 最近流量列表：最近的网络流量记录

**使用说明**：
- 点击各卡片可跳转到相应的详细页面
- 流量列表中的流条目可点击查看详情

### 2. 网络流量分析

#### 2.1 所有流量

**路径**：`/network/traffic`

**功能**：展示系统捕获的所有网络流量。

**主要组件**：
- 流量列表：显示源IP、目标IP、协议、端口、流量大小、时间和风险等级
- 搜索框：用于筛选特定流量

**使用说明**：
- 使用搜索框可按IP地址、协议等条件筛选流量
- 点击详情按钮查看流量的详细信息

#### 2.2 进站流量

**路径**：`/network/traffic/inbound`

**功能**：专注于进入网络的流量分析。

**主要组件**：
- 与所有流量页面类似，但仅显示进站流量

**使用说明**：
- 操作方式与所有流量页面相同
- 特别关注来自外部的可疑连接

#### 2.3 出站流量

**路径**：`/network/traffic/outbound`

**功能**：专注于从网络发出的流量分析。

**主要组件**：
- 与所有流量页面类似，但仅显示出站流量

**使用说明**：
- 操作方式与所有流量页面相同
- 特别关注连接到可疑外部服务器的流量

#### 2.4 危险流量

**路径**：`/network/traffic/risk`

**功能**：集中展示被系统标记为危险的流量。

**主要组件**：
- 危险流量列表：显示源IP、目标IP、协议、端口、流量大小、时间和风险类型
- 风险类型标签：如端口扫描、暴力破解、恶意连接等

**使用说明**：
- 此页面的流量应优先处理
- 点击详情按钮查看风险详情和建议处理方法

#### 2.5 流量详情

**路径**：`/network/traffic/flow/:id`

**功能**：查看特定流量的详细信息。

**主要组件**：
- 流量基本信息：源IP、目标IP、协议、端口等
- 详细数据包信息
- 风险评估信息（如适用）

**使用说明**：
- 通过所有流量、进站流量、出站流量或危险流量页面点击详情按钮进入

#### 2.6 IP地理位置图

**路径**：`/network/geo`

**功能**：在地图上直观展示与网络通信的IP地理位置分布。

**主要组件**：
- 世界地图：标记IP地址的地理位置
- 连接线：展示网络与外部IP的连接关系
- 地区详情面板：显示选中地区的连接详情

**使用说明**：
- 在地图上查看连接分布
- 点击标记点查看该地区的详细连接信息

### 3. 主机分析

#### 3.1 IPv6活跃主机分析

**路径**：`/network/ipv6`

**功能**：分析IPv6网络中的活跃主机。

**主要组件**：
- 活跃主机列表：显示IPv6地址、活跃度、连接数等信息
- 详情按钮

**使用说明**：
- 点击详情按钮查看主机的详细活动记录

#### 3.2 远端主机

**路径**：`/hosts/remote-hosts`

**功能**：分析与网络有通信的外部主机。

**主要组件**：
- 远端主机列表：显示IP地址、主机名、地理位置、ASN、首次连接、最后连接和活跃度
- 详情按钮

**使用说明**：
- 点击详情按钮查看该主机的详细信息和与网络的通信记录

#### 3.3 风险主机

**路径**：`/hosts/risk-hosts`

**功能**：集中展示被系统标记为危险的主机。

**主要组件**：
- 危险主机列表：显示IP地址、主机名、地理位置、风险类型、风险等级等信息
- 详情按钮

**使用说明**：
- 此页面的主机应优先处理
- 点击详情按钮查看风险详情和建议处理方法

#### 3.4 AS分布统计

**路径**：`/hosts/as-distribution`

**功能**：分析与网络通信的主机所属的自治系统(AS)分布。

**主要组件**：
- AS分布图表：展示不同AS的连接数量
- AS详细列表：显示AS编号、名称、国家、连接数等信息

**使用说明**：
- 通过图表可直观了解网络对外连接的AS分布
- 点击列表中的AS可查看该AS的详细连接信息

#### 3.5 国家分布统计

**路径**：`/hosts/country-distribution`

**功能**：分析与网络通信的主机所在国家/地区分布。

**主要组件**：
- 国家/地区分布图表：展示不同国家/地区的连接数量
- 国家/地区详细列表：显示国家/地区名称、连接数等信息

**使用说明**：
- 通过图表可直观了解网络对外连接的地理分布
- 点击列表中的国家/地区可查看该地区的详细连接信息

#### 3.6 基于主机的流量分析

**路径**：`/hosts/host-based`

**功能**：按主机分析网络流量情况。

**主要组件**：
- 主机流量图表：展示各主机的流量占比
- 主机流量列表：显示主机IP、流量大小、连接数等信息

**使用说明**：
- 通过图表了解网络流量的主机分布
- 点击列表中的主机可查看该主机的详细流量信息

### 4. IPv6地址分析

#### 4.1 IPv6地址监控

**路径**：`/address/address-monitoring`

**功能**：监控IPv6地址的活动和状态。

**主要组件**：
- 地址监控列表：显示IPv6地址、状态、活跃度、最后活动时间等信息
- 详情按钮

**使用说明**：
- 点击详情按钮查看地址的详细监控信息

#### 4.2 IPv6活跃地址分析

**路径**：`/address/active-detection`

**功能**：分析IPv6网络中的活跃地址。

**主要组件**：
- 地址信息卡片：显示IP地址、MAC地址、ASN信息等
- 安全指标卡片：显示行为异常计数、活动时间范围等
- 详细分析选项卡：包括流量统计、连接服务器、TCP统计和安全事件

**使用说明**：
- 输入IPv6地址进行查询
- 查看地址的详细信息和活动记录

#### 4.3 IPv6地址统计

**路径**：`/address/statistics`

**功能**：提供IPv6地址的统计分析。

**主要组件**：
- 统计卡片：显示活跃地址总数、前缀数量、平均命中率
- 生成方式分布图：展示不同生成方式的地址数量占比
- 前缀分布图：展示不同前缀的地址数量分布
- 前缀命中率表：显示各前缀的命中率详情

**使用说明**：
- 通过图表了解IPv6地址的分布情况
- 通过命中率表识别高效和低效的前缀

#### 4.4 生成模式分析

**路径**：`/address/pattern-analysis`

**功能**：分析IPv6地址的生成模式。

**主要组件**：
- 过滤器：按前缀、生成方式、状态筛选地址
- 地址列表：显示IPv6地址、前缀、接口标识、MAC地址、生成方式、状态等信息
- 详情按钮

**使用说明**：
- 使用过滤器筛选特定类型的地址
- 点击详情按钮查看地址的详细信息

### 5. 风险管理

## 总结

IPv6网络检测分析系统提供了全面的IPv6网络监控和分析功能，包括网络流量分析、主机分析、IPv6地址分析和风险管理等。通过直观的可视化界面和详细的数据展示，帮助管理员全面了解网络状况，及时发现并处理潜在安全风险，保障网络安全稳定运行。

## 系统操作指南

### 常见操作流程

1. **发现可疑流量**：
   - 在仪表盘查看总体情况
   - 进入危险流量页面查看详情
   - 分析流量来源和目的地


2. **监控特定主机**：
   - 在本地主机或远端主机页面找到目标主机
   - 点击详情按钮查看主机活动
   - 点击监控按钮加入重点监控
   - 定期检查主机活动报告

3. **分析IPv6地址**：
   - 在活跃地址检测页面输入地址
   - 查看地址详细信息和活动记录
   - 分析地址生成方式和行为模式
   - 决定是否需要进一步监控

4. **评估安全风险**：
   - 查看端口风险页面
   - 分析开放端口的必要性和风险
   - 查看IP地理位置图了解连接分布
   - 制定相应的安全策略

### 注意事项

1. 系统默认使用管理员账户登录，请妥善保管登录凭证
2. 系统数据会定期更新，刷新页面可获取最新数据
3. 对于高风险警报，建议及时处理并记录处理结果

## 故障排除

### 常见问题

1. **页面加载缓慢**：
   - 检查网络连接
   - 减少同时打开的页面数量
   - 清除浏览器缓存

2. **数据不更新**：
   - 刷新页面
   - 检查系统后台服务是否正常运行
   - 联系系统管理员

3. **操作无响应**：
   - 检查浏览器兼容性（推荐使用Chrome或Firefox）
   - 重新登录系统
   - 清除浏览器缓存和Cookie
