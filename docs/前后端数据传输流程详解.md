## 🏗️ 架构概览

系统采用**前后端分离**架构：

```
┌─────────────────────────────────────────────────────────┐
│                    浏览器（用户）                          │
└────────────────────┬────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────┐
│           前端层 (Vue 3 + TypeScript)                    │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐     │
│  │  Views   │─▶│ Services │─▶│  Axios Request   │     │
│  │(页面组件) │  │ (API服务) │  │  (HTTP客户端)    │     │
│  └──────────┘  └──────────┘  └──────────────────┘     │
└────────────────────┬────────────────────────────────────┘
                     │ HTTP/HTTPS
                     ▼
┌─────────────────────────────────────────────────────────┐
│          Vite代理 (开发环境) / Nginx (生产环境)           │
└────────────────────┬────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────┐
│          后端层 (Python + Flask)                         │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐     │
│  │  Routes  │─▶│Services  │─▶│   Repositories   │     │
│  │  (路由)  │  │(业务逻辑) │  │  (数据访问层)     │     │
│  └──────────┘  └──────────┘  └──────────────────┘     │
└────────────────────┬────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────┐
│             数据存储层                                    │
│  ┌─────────────┐        ┌─────────────┐               │
│  │ PostgreSQL  │        │   Redis     │               │
│  │  (数据库)    │        │  (缓存)     │               │
│  └─────────────┘        └─────────────┘               │
└─────────────────────────────────────────────────────────┘
```

### 技术栈分工

| 层级 | 技术 | 职责 |
|------|------|------|
| **前端** | Vue 3 + TypeScript + Vuetify | 用户界面、交互逻辑、数据展示 |
| **传输** | HTTP(S) + JSON | 前后端通信协议 |
| **代理** | Vite (开发) / Nginx (生产) | 请求转发、负载均衡 |
| **后端** | Python + Flask | API服务、业务逻辑、数据处理 |
| **存储** | PostgreSQL | 持久化数据存储 |
| **缓存** | Redis | 数据缓存、性能优化 |

## 🔄 完整数据流转图

### 请求过程（用户操作 → 后端处理）

```
1. 用户操作
   └─▶ 在Vue组件中触发事件
       └─▶ 调用Composables或直接调用Service
           └─▶ Service调用Axios实例
               └─▶ 请求拦截器添加token
                   └─▶ Vite代理转发到后端
                       └─▶ Flask接收请求
                           └─▶ 路由分发
                               └─▶ Controller处理
                                   └─▶ Service业务逻辑
                                       └─▶ Repository查询数据库
                                           └─▶ 返回数据
```

### 响应过程（后端数据 → 前端展示）

```
1. Repository返回查询结果
   └─▶ Service封装业务数据
       └─▶ Controller返回HTTP响应
           └─▶ Flask包装JSON响应
               └─▶ Vite代理转发到前端
                   └─▶ 响应拦截器处理状态码
                       └─▶ Service Promise resolve
                           └─▶ 更新响应式数据
                               └─▶ Vue重新渲染
                                   └─▶ 用户看到最新数据
```

**文件**: `backend_v2/app/controllers/traffic_controller.py`

```python
from flask import request
from flask_restful import Resource
from app.services.traffic_service import TrafficService

class TrafficController(Resource):
    
    def __init__(self):
        self.traffic_service = TrafficService()
    
    def get(self):
        """GET /api/network/traffic - 获取流量列表"""
        try:
            # 1. 获取查询参数
            params = {
                'page': request.args.get('page', 1, type=int),
                'page_size': request.args.get('page_size', 10, type=int),
                'src_ip': request.args.get('src_ip'),
                'dst_ip': request.args.get('dst_ip'),
                'protocol': request.args.get('protocol'),
                # ... 其他参数
            }
            
            # 2. 调用Service层
            result = self.traffic_service.get_traffic_list(params)
            
            # 3. 返回响应
            if result.get('success'):
                return result['data']
            else:
                return {
                    'error': result.get('error'),
                    'message': result.get('message')
                }, 400
                
        except Exception as e:
            logger.error(f"流量列表接口异常: {str(e)}")
            return {
                'error': 'internal_error',
                'message': '服务器内部错误'
            }, 500
```

**Controller职责**:

#### 2.3 Service业务逻辑

**文件**: `backend_v2/app/services/traffic_service.py`

```python
class TrafficService:
    
    def __init__(self):
        self.traffic_repo = TrafficRepository()
        self.cache = get_cache_manager()
    
    def get_traffic_list(self, params: Dict[str, Any]) -> Dict[str, Any]:
        """获取流量列表"""
        
        # 1. 生成缓存键
        cache_key = self._generate_cache_key("traffic_list", params)
        
        # 2. 尝试从缓存获取
        if self.cache:
            cached_result = self.cache.get(cache_key)
            if cached_result:
                logger.info("从缓存获取流量列表")
                return cached_result
        
        # 3. 构建查询筛选条件
        filters = self._build_filters(params)
        
        # 4. 调用Repository查询数据
        skip = (page - 1) * page_size
        items = self.traffic_repo.get_paginated(
            skip=skip,
            limit=page_size,
            filters=filters
        )
        
        # 5. 统计总数
        total = self.traffic_repo.count(filters=filters)
        
        # 6. 封装响应
        result = {
            'success': True,
            'data': {
                'items': [item.to_dict() for item in items],
                'pagination': {
                    'page': page,
                    'page_size': page_size,
                    'total': total,
                    'total_pages': (total + page_size - 1) // page_size
                }
            }
        }
        
        # 7. 缓存结果（5分钟）
        if self.cache:
            self.cache.set(cache_key, result, timeout=300)
        
        return result
```

**Service职责**:
- ✅ 业务逻辑处理
- ✅ 数据验证和转换
- ✅ 调用Repository
- ✅ 缓存管理
- ✅ 错误处理

#### 2.4 Repository数据访问

**文件**: `backend_v2/app/repositories/traffic_repository.py`

```python
class TrafficRepository(BaseRepository):
    
    def __init__(self):
        super().__init__(FlowRecord)
    
    def get_paginated(self, skip, limit, filters, order_by, order_desc):
        """获取分页的流量记录"""
        
        # 1. 构建查询
        query = self.build_query(filters, order_by, order_desc)
        
        # 2. 添加分页
        query = query.offset(skip).limit(limit)
        
        # 3. 执行查询
        results = query.all()
        
        # 4. 返回记录列表
        return results
```

**Repository职责**:
- ✅ SQL查询构建
- ✅ 数据库交互
- ✅ 数据模型转换

### 阶段4: 前端接收响应

#### 4.1 响应拦截器处理

**文件**: `frontend_v3/src/services/request.ts`

```typescript
// 响应拦截器
request.interceptors.response.use(
    (response: AxiosResponse) => {
        // 检查业务状态码
        if (response.data && response.data.code) {
            const statusCode = response.data.code
            if (statusCode === 10401) {
                // Token过期
                window.localStorage.removeItem('access_token')
                message.error('请求令牌已过期')
                window.location.href = '/login'
            }
        }
        return response
    },
    (error) => {
        // 处理HTTP错误
        if (error.response) {
            const statusCode = error.response.status
            if (statusCode === 401) {
                message.error('未授权访问')
            } else if (statusCode === 500) {
                message.error('服务器内部错误')
            } else if (statusCode === 404) {
                message.error('请求的资源不存在')
            }
        }
        return Promise.reject(error)
    }
)
```

## 📝 总结

前后端数据传输流程：

```
用户操作
    ↓
Vue组件
    ↓
Service (API封装)
    ↓
Request (Axios)
    ↓
请求拦截器 (添加token)
    ↓
Vite代理 (转发)
    ↓
Flask路由 (匹配)
    ↓
Controller (处理参数)
    ↓
Service (业务逻辑)
    ↓
Repository (数据访问)
    ↓
PostgreSQL (查询)
    ↓
Repository (返回结果)
    ↓
Service (封装响应)
    ↓
Controller (HTTP响应)
    ↓
Vite代理 (转发)
    ↓
响应拦截器 (错误处理)
    ↓
Service Promise (resolve)
    ↓
Vue数据更新
    ↓
组件重新渲染
    ↓
用户看到数据
```

**核心要点**:
1. ✅ 前后端通过HTTP + JSON通信
2. ✅ 请求经过拦截器处理
3. ✅ 后端分层架构清晰
4. ✅ 缓存提高性能

6. ✅ 类型安全
