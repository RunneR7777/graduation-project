## 📖 项目简介

**FuXi网络分析系统** 是一个专为IPv6网络环境设计的现代化流量监控与智能分析平台。系统采用前后端分离架构，集成了人工智能技术，为网络管理员提供全方位的网络流量分析、安全监控和智能决策支持。

### ✨ 核心亮点

- 🎯 **IPv6原生支持** - 完整支持IPv6地址类型和网络协议
- 🤖 **AI智能分析** - 集成大语言模型，支持自然语言查询
- 📊 **实时可视化** - 丰富的图表和仪表盘展示
- 🔒 **安全监控** - 多层次风险评估和异常检测
- ⚡ **高性能** - 基于PostgreSQL的高效数据处理
- 🎨 **现代化UI** - 响应式设计，优秀的用户体验

## 🚀 快速开始

### 环境要求

- **Node.js** >= 16.0.0
- **Python** >= 3.8
- **PostgreSQL** >= 13.0
- **Redis** >= 6.0 (可选)

### 安装部署

#### 1. 克隆项目

```bash
git clone <repository-url>
cd fuxi-network-analysis
```

#### 2. 后端部署

```bash
# 进入后端目录
cd backend

# 安装Python依赖
pip install -r requirements.txt

# 配置数据库
# 编辑 database/database.ini 配置数据库连接

# 运行数据库迁移
python database/migrations/combined_migration.sql

# 启动后端服务
python run.py
```

#### 3. 前端部署

```bash
# 进入前端目录
cd frontend_v3

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

#### 4. Docker部署

```bash
# 构建镜像
docker build -t fuxi-backend ./backend
docker build -t fuxi-frontend ./frontend_v3

# 运行容器
docker-compose up -d
```

### 访问系统

- **前端地址**: http://localhost:3000
- **后端API**: http://localhost:5001
- **API文档**: http://localhost:3000/developer/api

## 🔧 配置说明

### 环境变量

#### 后端配置

```bash
# 数据库配置
DB_HOST=localhost
DB_PORT=5432
DB_NAME=fuxi_network
DB_USER=postgres
DB_PASSWORD=your_password

# AI服务配置
OPENAI_API_KEY=your_openai_key
DEEPSEEK_API_KEY=your_deepseek_key

# 系统配置
FLASK_ENV=production
SECRET_KEY=your_secret_key
```

#### 前端配置

```bash
# API配置
VITE_API_BASE_URL=/api/
VITE_APP_TITLE=FuXi网络分析系统

# 环境配置
VITE_NODE_ENV=production
```

### 数据库配置

系统使用PostgreSQL数据库，主要表结构：

- **flow_records** - 流量记录表（支持IPv6）
- **chat_sessions** - 聊天会话表
- **chat_messages** - 聊天消息表
- **anomaly_detection** - 异常检测结果表
