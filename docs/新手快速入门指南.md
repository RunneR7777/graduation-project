## 🚀 快速开始（3步即可运行）

### 第一步：启动数据库

系统依赖PostgreSQL数据库，确保数据库服务正在运行：

```bash
# 检查数据库状态
sudo systemctl status postgresql

# 如果未运行，启动数据库
sudo systemctl start postgresql
```

### 第二步：启动后端服务

```bash
cd /home/ui
python3 backend/run.py
```

后端将运行在：`http://localhost:5001`

### 第三步：启动前端界面

```bash
cd /home/ui/frontend_v3
npm run dev
```

前端将运行在：`http://localhost:3000`

### 🎉 完成！现在可以访问系统了

打开浏览器访问：**http://localhost:3000**

## 📱 系统界面快速导览

### 1. 仪表盘（Dashboard）

**路径**: `http://localhost:3000/dashboard`

**功能**: 系统总览
- 📊 流量统计卡片（活跃流、危险流）
- 🖥️ 主机统计卡片（本地主机、远程主机）
- 📍 IPv6地址统计
- ⚠️ 端口风险提示
- 📈 流量趋势图表

**新手建议**: 这是您首先应该查看的地方，了解整体网络状况。

### 2. 网络流量分析

**主要路径**:
- 所有流量: `/network/traffic`
- 进站流量: `/network/traffic/inbound`
- 出站流量: `/network/traffic/outbound`
- 危险流量: `/network/traffic/risk`

**功能**: 查看网络流量详情
- 📋 流量列表（源IP、目标IP、协议、端口、大小、时间）
- 🔍 搜索筛选功能
- 📊 流量统计图表

**新手建议**: 
- 从"所有流量"开始浏览
- 点击"危险流量"查看需要关注的异常连接

### 3. 主机分析

**主要路径**:
- IPv6活跃主机: `/network/ipv6`
- 远端主机: `/hosts/remote-hosts`
- 风险主机: `/hosts/risk-hosts`
- AS分布: `/hosts/as-distribution`
- 国家分布: `/hosts/country-distribution`

**功能**: 分析主机活动
- 📊 查看与网络通信的主机
- 🌍 地理位置分布
- 🏢 AS（自治系统）分布
- ⚠️ 识别危险主机

**新手建议**: 查看"AS分布"和"国家分布"了解网络连接的来源。

### 4. IPv6地址分析

**主要路径**:
- 地址监控: `/address/address-monitoring`
- 活跃检测: `/address/active-detection`
- 统计分析: `/address/statistics`
- 生成模式: `/address/pattern-analysis`

**功能**: IPv6地址详细分析
- 🔍 检测活跃地址
- 📊 统计分析
- 🔬 生成模式识别

**新手建议**: 在"统计分析"页面查看地址分布情况。

### 5. 风险管理

**主要路径**:
- 端口风险: `/risk/ports`

**功能**: 安全风险分析
- 🚨 识别开放的危险端口
- 📊 风险评估
- 💡 提供处理建议

**新手建议**: 定期检查端口风险，及时处理高危端口。

### 6. ChatAI 智能助手

**路径**: `/chatai`

**功能**: AI智能分析助手
- 💬 使用自然语言查询网络状况
- 🤖 MCP多智能体系统
- 📊 智能数据分析

**新手建议**: 尝试向ChatAI提问，如"显示最近的危险流量"。

## 🎓 常见使用场景

### 场景1：发现可疑流量

1. 进入 **仪表盘** → 查看"危险流"卡片
2. 点击进入 **危险流量页面**
3. 查看流量详情（源IP、目标IP、协议）
4. 点击 **详情按钮** 获取更多信息
5. 根据情况决定是否采取行动

### 场景2：监控特定主机

1. 进入 **远端主机页面**
2. 使用搜索框输入主机IP
3. 查看主机的活跃度和连接历史
4. 点击详情查看更多信息

### 场景3：分析IPv6地址

1. 进入 **IPv6地址分析** → **活跃检测**
2. 输入要查询的IPv6地址
3. 查看地址的详细信息：
   - 行为模式
   - 流量统计
   - 连接记录
   - 安全事件

### 场景4：评估安全风险

1. 进入 **风险评估** → **端口风险**
2. 查看开放端口列表
3. 重点关注"高风险"端口
4. 点击详情查看具体威胁和建议

## 🛠️ 系统架构说明

### 项目结构

```
/home/ui/
├── backend/          # 旧版后端（Python Flask）
├── backend_v2/      # 新版后端（Python Flask + 分层架构）
├── frontend_v3/     # 前端（Vue 3 + TypeScript + Vuetify）
└── logs/            # 日志文件
```

### 前后端通信

- **前端**: Vue 3应用，运行在端口 3000
- **后端**: Flask API服务
  - 旧版：端口 5001
  - 新版：端口 5002
- **数据库**: PostgreSQL（端口 5433）
- **缓存**: Redis（可选）

### 技术栈

**前端**:
- Vue 3 + TypeScript
- Vuetify 3（UI组件库）
- Pinia（状态管理）
- ECharts（图表）
- Axios（HTTP请求）

**后端**:
- Python + Flask
- SQLAlchemy（ORM）
- PostgreSQL（数据库）
- Redis（缓存）

## 🔧 常见问题解决

### Q1: 页面显示"ERR_CONNECTION_REFUSED"

**原因**: 后端服务未启动

**解决**:
```bash
# 启动后端
cd /home/ui/backend_v2
source venv/bin/activate
python run.py
```

### Q2: 数据一直加载或不显示

**原因**: 数据库连接问题

**解决**:
```bash
# 检查数据库状态
sudo systemctl status postgresql

# 检查后端日志
tail -f /home/ui/logs/backend_v2.log
```

### Q3: 修改端口配置

**前端端口**（端口 3000）:
```bash
# 编辑 vite.config.ts
vim frontend_v3/vite.config.ts
```

**后端端口**:
```bash
# 编辑 backend_v2/run.py
vim backend_v2/run.py
# 修改 port 参数
```

### Q4: 安装依赖

**前端**:
```bash
cd frontend_v3
npm install
```

**后端**:
```bash
cd backend_v2
source venv/bin/activate
pip install -r requirements.txt
```
